# EJ Korean

외국인에게 한국어를 가르치는 개인 강사(EJ)를 위한 웹사이트. 인스타그램 [@ej.korean](https://www.instagram.com/ej.korean)과 연결되는 브랜드입니다.

## 주요 페이지

- `/` — 강사 소개 페이지
- `/payment` — 수업 결제 페이지 (결제 연동은 추후 진행 예정, 현재는 신청서 UI만 제공)

## 개발

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)에서 확인할 수 있습니다.

## 기술 스택

- Next.js (App Router) + TypeScript
- Tailwind CSS
